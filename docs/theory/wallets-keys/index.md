# Wallets and keys

A wallet is a tool for managing the private keys that control on-chain assets. This domain covers the concepts behind key custody: seed phrases, address derivation standards, and the difference between self-custody and custodial custody.

## Categories

- [Hot and cold wallets]({{ 'theory/wallets-keys/hot-cold-wallets' | relative_url }}) — online versus offline key custody.
- [Mnemonic phrases (BIP-39)]({{ 'theory/wallets-keys/mnemonics' | relative_url }}) — human-readable seed phrases.
- [Hierarchical derivation (BIP-32/44)]({{ 'theory/wallets-keys/hd-wallets' | relative_url }}) — deriving multiple addresses from one seed.
- [Private and public keys]({{ 'theory/wallets-keys/keys' | relative_url }}) — the core key material.
