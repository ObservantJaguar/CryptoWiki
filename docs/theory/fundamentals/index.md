# Blockchain fundamentals

This domain covers the core building blocks of any blockchain: what a block is, how hashing chains blocks together, how Merkle trees commit to large state, and what makes a chain tamper-evident. These concepts are shared by almost every protocol, from Bitcoin to Ethereum and beyond.

## Categories

- [Blocks and chaining]({{ 'theory/fundamentals/blocks-chaining' | relative_url }}) — structure of a block, block height, and the hash chain.
- [Hashing]({{ 'theory/fundamentals/hashing' | relative_url }}) — how hash functions bind block data and detect tampering.
- [Merkle trees]({{ 'theory/fundamentals/merkle-trees' | relative_url }}) — compact commitments to sets of transactions.
- [What is a blockchain]({{ 'theory/fundamentals/single-blockchain' | relative_url }}) — the canonical model: a distributed ledger shared across nodes.
