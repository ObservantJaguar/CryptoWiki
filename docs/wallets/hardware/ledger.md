# Ledger

**Ledger** is a French hardware-wallet company producing the popular **Nano S** and **Nano X** USB/smartphone-connected devices, plus the newer **Flex** and **Stax** models. Ledger devices are widely used for self-custody across many chains.

## What it is

- Hardware cold wallets: keys stored in a certified secure element (STMicroelectronics CC EAL5+ chip).
- Works with the **Ledger Live** desktop/mobile app for portfolio management and transactions.
- **Proprietary firmware**, closed-source, though the surrounding app ecosystem is extensive.

> **License:** Proprietary — not open source.

## Key features

- **Multi-chain** — supports Bitcoin, Ethereum, Solana, and hundreds of coins/tokens via apps.
- **Bluetooth** on Nano X for mobile pairing; USB on Nano S.
- **Passphrase support** (BIP-39) and PIN protection.
- **Ledger Live** — swap, buy, stake (Lido, etc.) directly from the app.
