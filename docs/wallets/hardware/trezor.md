# Trezor

**Trezor** is a hardware wallet brand by SatoshiLabs (Czech Republic). Its devices — the **Model T**, **Model One**, and **Safe 3/5** — store keys offline and sign transactions, with a strong reputation for open-source transparency and open hardware.

## What it is

- Hardware cold wallets with keys kept in an offline environment.
- Managed via the **Trezor Suite** desktop/web/mobile application.
- **Open-source firmware** (Moon/Core) — auditable by the community.

## Key features

- **Open-source** firmware and client software.
- BIP-39 seed generation with optional passphrase (25th word).
- **Model T** adds a touchscreen; **Safe 5** adds a secure element + digits display.
- **Trezor Suite** — portfolio, exchange, staking, and third-party app connections.
- Supports many coins (Bitcoin/EVM/native + more).
