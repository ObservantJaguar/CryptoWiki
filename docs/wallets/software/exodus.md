# Exodus

**Exodus** is a user-friendly, multi-asset desktop and mobile software wallet focused on ease of use, a built-in exchange, and portfolio tracking across hundreds of cryptocurrencies.

## What it is

- A **hot/software wallet** storing keys locally on the user's device.
- **Closed-source** desktop app + mobile client.
- Known for its polished UI and breadth of supported assets.

## Key features

- **Multi-coin support** — many chains and tokens in one portfolio view.
- **Built-in swap** (via integration with exchange partners) inside the wallet.
- **Hardware wallet integration** — pairs with Trezor for reduced hot-key exposure.
- **Web3 browser** on mobile for dApp/DeFi access.
- Staking support for select assets.

## Security notes

As a hot wallet, keep only small, everyday balances in Exodus; use hardware/cold storage for significant holdings. The app's closed-source nature means code is not publicly auditable.

> **License:** Proprietary — not open source.
