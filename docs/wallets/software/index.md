# Software wallets

Software (hot) wallets store private keys on a connected device — desktop, mobile, or browser — and offer convenience at the cost of a larger attack surface. They are best for everyday, small-value use; larger holdings belong in cold storage.

## Categories

- **Browser extensions** — MetaMask (EVM), Phantom (Solana), etc.
- **Desktop wallets** — Electrum (Bitcoin), Exodus (multi-coin), etc.
- **Mobile wallets** — many multi-chain apps.

## Shared advice

- Only install from official stores/official sites; verify signatures.
- Back up the **seed phrase** immediately after creation.
- Consider avoiding web-based "wallets" that keep keys in browsers.
