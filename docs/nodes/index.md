# Node software

Protocol implementations that let you run, validate, and interact with a blockchain network. This domain catalogs full and consensus clients by network.

## Domains

- [Bitcoin node software]({{ 'nodes/bitcoin' | relative_url }}) — Bitcoin Core and related tooling.
- [Ethereum node software]({{ 'nodes/ethereum' | relative_url }}) — Geth, Nethermind, Erigon, and the execution/consensus-client split.
- [Alternative network nodes]({{ 'nodes/alt-nodes' | relative_url }}) — Solana, Polkadot, and other ecosystems.
