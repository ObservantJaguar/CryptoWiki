# Bitcoin Knots

**Bitcoin Knots** is a community-driven, alternative Bitcoin full-node implementation maintained as a fork and complement to Bitcoin Core. It keeps Bitcoin Core compatibility while adding experimental policy options, extra mempool controls, and extended features not yet merged upstream.

## What it is

- A full node (bitcoind / bitcoin-qt) that follows Bitcoin Core's release line but carries patches Bitcoin Core maintainers did not merge.
- **Open-source** — released under the same permissive license as Core.
- Often used by miners and power users who want additional policy flexibility.

## Key features

- Full blockchain validation and P2P networking identical in spirit to Bitcoin Core.
- Extra **mempool and policy tunables** for miners (e.g. fee estimation, package relay enhancements).
- Extended RPC and configuration options compared with vanilla Core.
- Follows Core's upgrade cycle with a slightly different cadence.
