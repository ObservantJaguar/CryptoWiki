# Alternative network nodes

Node software for blockchain networks other than Bitcoin and Ethereum. These ecosystems often require a single full node that runs from a precompiled binary or containerized image.

## Domains

- [Solana]({{ 'nodes/alt-nodes/solana' | relative_url }}) — validator and RPC node software.
- [Polkadot]({{ 'nodes/alt-nodes/polkadot' | relative_url }}) — substrate-based relay/parachain nodes.
- [Other networks]({{ 'nodes/alt-nodes/other-networks' | relative_url }}) — brief notes on further ecosystems (Litecoin, Dogecoin, Cardano, Cosmos, ...).
