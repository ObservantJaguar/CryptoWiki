# Dune Analytics

**Dune Analytics** is a platform that decodes raw blockchain events into structured tables you can query with **SQL**, then visualize in dashboards. It is the de-facto standard for community on-chain analysis.

## What it is

- A hosted service that indexes and **decodes** Ethereum (and many EVM + non-EVM chains) into queryable datasets.
- **Free to use** for public dashboards; paid tiers for private queries and API access.
- **Closed-source** service (the community dashboard querying is public).

## Key features

- **SQL query editor** — write SQL over decoded tables (transfers, swaps, mints, etc.).
- **Dashboards** — turn queries into charts/summary tables shared publicly.
- **Spellbook** — community-maintained spell tables standardizing common data models.
- **Wizard/API** — programmatic access to query results.
- **Decoding framework** — custom contract decoding via a spell system.

## Use cases

Protocol growth metrics, token flows, whale tracking, TVL, and DEX volume analysis. Ideal for engineers and analysts who already know SQL.
