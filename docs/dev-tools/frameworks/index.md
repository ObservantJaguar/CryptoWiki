# Smart-contract frameworks

Frameworks provide compilation, testing, deployment, and scripting for smart contracts, streamlining the EVM development lifecycle. They abstract away toolchain plumbing so developers focus on contract logic.

## Categories

- [Hardhat]({{ 'dev-tools/frameworks/hardhat' | relative_url }}) — the de-facto JavaScript/TypeScript development environment.
- [Foundry]({{ 'dev-tools/frameworks/foundry' | relative_url }}) — the fast Rust-based Solidity toolchain (forge/cast/anvil).
- [Truffle/Hardhat legacy & Remix]({{ 'dev-tools/frameworks/truffle-remix' | relative_url }}) — earlier frameworks and the browser IDE.
