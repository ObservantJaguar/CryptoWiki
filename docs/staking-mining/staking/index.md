# Staking

**Staking** is the process of locking up cryptocurrency to secure and operate a proof-of-stake network. Validators run client software, propose/attest blocks, and earn rewards; users can stake directly or via services.

## Ways to stake

- **Solo staking** — run your own validator and stake the full requirement (e.g. 32 ETH on Ethereum).
- **Liquid staking** — deposit into Lido/Rocket Pool and receive a liquid token (stETH/rETH) while a validator does the work.
- **Centralized staking** — stake on exchanges (custodial).
