# 1inch Network

**1inch Network** is a decentralized exchange aggregator that finds the most efficient trading path across multiple DEXes and liquidity sources. It was born from a hackathon project and has grown into one of the most used aggregators, also operating its own AMMs (Fusion, Limit Order Protocol).

## What it is

- An **aggregation protocol** plus a set of DeFi tools on Ethereum and major EVM chains.
- **Open-source** smart contracts; launchable interface.
- **1INCH** — the governance token.

## Key features

- **Pathfinder** — the routing algorithm that best-optimizes swaps to limit slippage and gas.
- **Fusion / limit-order protocol** — on-chain decentralized order book executed by keepers/delegates.
- **GasToken** for gas efficiency and gasless transactions options.
- **1inch Portfolio/Dashboard** for tracking.
- Token Shelter, Rabby-style safeguards for safer interaction.
