# Paraswap

**Paraswap** (now part of the Biconomy ecosystem) is a leading open-source DEX aggregator that routes swaps across Uniswap, Curve, Balancer, and many other venues to find the best execution. It has earned a reputation for transparency and low gas costs.

## What it is

- A **multi-path swap aggregator** for Ethereum and EVM chains.
- **Open-source** contracts with audited security.
- Aims for best price with minimal gas via optimal routing.

## Key features

- **Best-price routing** across dozens of DEXes and sources.
- **GasToken / EIP-3668** style optimizations for cheaper swaps.
- **Limit orders (Paraswap plug & limit order protocol)**.
- **Portfolio** dashboard and SDK for developers.
- **P2P / ParaBank** — later evolved into Biconomy's intent-based infrastructure.
